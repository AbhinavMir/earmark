Earmark

Your Audible library,
on your own Mac.

Earmark plays the audiobooks your account already owns. It streams a title straight away, keeps a copy as a plain M4B, and stays in step with the Audible app on your phone.

macOS 14 or later. Free, and the source is open.

Download for Mac Source on GitHub

Signed, but not notarised. The first open needs a right-click, then Open. Also needs ffmpeg: brew install ffmpeg

What it does

Plays without waiting

Press play and a title starts streaming. It downloads quietly behind you, and playback moves onto the file the moment it lands, at the same place in the book.

Keeps plain files

Titles are written to ~/Audiobooks as M4B, with chapters and cover art. Any other player can open them. Removing Earmark never removes your books.

Stays in step with your phone

It reads and writes the place Audible keeps, so a chapter begun on the train carries on at your desk. The later session wins, and you can undo the jump.

Behaves like a Mac application

Media keys, the Now Playing panel, and AirPods controls all work. Chapters, speed from 0.75× to 3×, a sleep timer, bookmarks, and search across title, author, narrator, and series.

Getting started

1. Install ffmpeg

brew install ffmpeg

2. Open Earmark and sign in

Sign-in happens on Amazon's own page inside the window. Earmark never sees your password. It registers this Mac as a device, the same way the phone application does, and keeps the credentials in a file only you can read.

3. Or build it yourself

git clone https://github.com/AbhinavMir/earmark
cd earmark && ./build-app.sh
open build/Earmark.app

About

Earmark reaches only the titles your own account already owns. It is not a way to obtain audiobooks, and the files it writes are yours to listen to rather than to hand out.

It is built on AudibleKit, a Swift client for the Audible API written from the wire protocol. Both are MIT licensed.
